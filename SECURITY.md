# Security Policy

## Supported Versions

As tian-shu doesn't provide an official release yet, please use the latest version to receive security updates.
Currently, we have two branches to maintain:
* main branch for tian-shu 2.x
* main-1.x branch for tian-shu 1.x

## Reporting a Vulnerability

Please go to https://github.com/jiel521125/TianShuFlow/security to report the vulnerability you find.
